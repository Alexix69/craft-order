# CraftOrder
Sistema web para mueblería artesanal con tres módulos: cotizador público de muebles a medida, panel de administración para catálogo y presupuestos, y tablero Kanban para artesanos. Notificaciones por email y seguimiento por token.

## Stack
- Java + Spring Boot
- PostgreSQL
- Maven
